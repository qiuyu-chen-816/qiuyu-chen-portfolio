## 怎么用

1. 双击 `index.html`，或把整个 `outputs` 文件夹拖进浏览器。
2. 点击任意作品图片可放大查看，支持左右方向键切换。
3. 视频：
   - 视频文件在 `assets/videos/` 文件夹里，点击任意视频卡片会弹出播放器。
   - 视频卡片使用统一的粉彩海报，你可以后续替换成每个视频的真实封面帧。

## 文件结构

- `index.html` — 页面结构
- `css/styles.css` — 视觉样式
- `js/main.js` — 动效、菜单、视频与图片弹窗
- `assets/works/` — 你的作品图片
- `assets/videos/` — 你的视频作品
- `assets/` — SVG 封面、视频海报与 favicon
